nijicha/skills

Claude Code plugins by nijicha, in one marketplace. Each plugin brings its own skills, subagents and MCP servers. Install only the ones you want.

Add the marketplace

Once, in Claude Code. After that, install any plugin below by name.

Claude Code
/plugin marketplace add nijicha/skills

Get the latest versions with /plugin marketplace update nijicha-skills.

Plugins

walkie

0.2.0-alpha

Narrated videos of a code change, for people outside engineering. Records your app, adds a Thai or English voice-over, captions and highlights in your team's look, and builds an MP4 to attach to a PR.

Brings
Skill walkie, a Sonnet subagent, and an MCP server
Needs
The walkie engine on an Apple Silicon Mac: brew install nijicha/tap/walkie
Install
/plugin install walkie@nijicha-skills
Setup guide → Source Engine

Issues

A problem with a plugin: open an issue in nijicha/skills. A problem with the walkie engine itself (recording, voice, video): nijicha/walkie-engine.
